Credits & Licenses

Every planet, moon, galaxy, black hole and landmark photograph in this app is a real image sourced from NASA, ESA, the Event Horizon Telescope collaboration, and photographers publishing through Wikimedia Commons. This page lists each image individually, with its photographer/agency, its exact license, and a link back to the original Commons file page for independent verification. Procedurally generated content (starfields, orbit lines, the cosmic-web particle structure, UI graphics) is original and created for this project — it isn't listed here.

License data pulled directly from the Wikimedia Commons API and verified live on 2026-08-18. If a source page's license changes upstream after that date, this list may lag — click through to the Commons page for the current terms before republishing.

Software & Data

Not images, but disclosed for completeness — the libraries and live data feeds this app depends on.

  • three.js — WebGL rendering engine. MIT License. Loaded from cdn.jsdelivr.net.
  • React — used to build the landing page only. MIT License.
  • Vite — bundles the landing page. MIT License.
  • Spaceflight News API — live space-news ticker. Public API, api.spaceflightnewsapi.net.
  • Where the ISS at? — live ISS position. Public API, api.wheretheiss.at.
  • Google Gemini — powers the in-app AI assistant. Accessed server-side via a Netlify Function; no image or text from this app is used to train third-party models beyond Google's standard API terms.
